# XBitSound

**A browser-based bitcrusher: give any song a retro 8-bit sound.**

🔗 **Live demo:** https://apoben.github.io/XBitSound/

## Features
- Drag & drop MP3 / WAV files
- Adjustable **bit depth** and **sample-rate reduction** (sample & hold)
- Real-time audio visualizer and A/B playback
- Export the processed track as WAV
- 100 % client-side (Web Audio API); installable as a PWA

## Tech Stack
React · Vite · Web Audio API · Tailwind CSS · Framer Motion

## Run Locally
```bash
npm install
npm run dev
```
